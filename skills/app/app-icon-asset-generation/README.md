# App Icon Asset Generation

Generate a complete, production-ready icon asset set for a multi-platform application from an approved high-resolution source logo.

## Files

| File | Purpose |
|---|---|
| `SKILL.md` | The skill definition |
| `README.md` | This file |
| `example-input.md` | Example input for this skill |
| `example-output.md` | Example output produced by this skill |

## What this skill produces

- Transparent PNGs at standard sizes (2048, 1024, 512, 192, 120px)
- Simplified micro icon for small UI placements (28x28, 32x32)
- SVG micro icon for scalable UI use
- Favicon candidates (PNG and ICO)
- Individual downloadable files — not a combined contact sheet

## Target platforms

Android, iOS, Flet, Flutter, web (PWA), desktop.
