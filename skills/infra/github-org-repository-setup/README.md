# GitHub Org Repository Setup

Set up a new GitHub repository in an organisation with correct access, security, and baseline branch protection.

## What this skill does

Guides you through creating and configuring organisation-owned GitHub repositories without role surprises or accidental billing changes. It emphasises immediate admin-role verification, cautious security configuration, and minimum viable branch protection for lab environments.

## When to use it

- Creating a new repository inside a GitHub organisation
- Verifying effective permissions after API-based creation
- Applying baseline branch safety rules in lab or proof-of-concept repos
- Reviewing GitHub security settings under billing policy constraints

## Example use cases

- API-created repo where creator unexpectedly has write instead of admin
- New internal lab repo that needs safe defaults without heavy governance
- Team standardisation of first-day repository setup across projects
