# AI Skills

Skills for designing, building, and evaluating AI agents and language model applications.

These skills cover the delivery lifecycle for AI-powered systems: agent design, prompt engineering, RAG pipeline architecture, LLM evaluation, and agentic workflow design. They are intended to be practical and opinionated — encoding decisions and trade-offs practitioners face when building production AI systems.

## Adding a new AI skill

Use the [skill template](../../contribute/templates/skill-template/) as your starting point. See [CONTRIBUTING.md](../../contribute/CONTRIBUTING.md) for submission guidance.

Claude Code users can run `/mtx capture` in any project to record discoveries, then `/mtx update <skill-name>` from the skills repo to apply them.
