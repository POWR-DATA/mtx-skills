# Dimensional Model Designer

Design a star schema or dimensional model for BI and analytics reporting use cases.

## What this skill does

This skill takes a reporting or analytics requirement and produces a structured dimensional model design, including fact tables, dimension tables, measures, relationships, and key design decisions such as slowly changing dimension strategy.

## When to use it

- You have a reporting or dashboard requirement and need to structure data for BI consumption
- You are designing a semantic model or metric layer and need an underlying dimensional structure
- You are building an analytics data layer and need a consistent model design
- You need to document or review an existing dimensional model

## Example use cases

- Designing a star schema for sales performance reporting
- Modelling a finance P&L reporting structure
- Designing a customer analytics dimensional model
- Structuring a workforce reporting data layer
