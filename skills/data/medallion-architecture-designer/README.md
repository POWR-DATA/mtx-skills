# Medallion Architecture Designer

Design a bronze/silver/gold lakehouse data layer architecture.

## What this skill does

This skill takes a source system, ingestion scenario, and consumer requirements and produces a structured medallion architecture design covering bronze (raw), silver (standardised), and gold (consumption-ready) layers.

## When to use it

- You are designing a new data pipeline and need to plan the layer structure
- You are onboarding a new source system to a lakehouse platform
- You need to review or document an existing layered data architecture
- You are planning a migration from a traditional warehouse pattern to a lakehouse pattern

## Example use cases

- Designing a lakehouse architecture for daily sales file ingestion
- Planning a CDC-based ingestion pipeline for an ERP source system
- Structuring a bronze/silver/gold approach for an API data feed
- Designing the data layers for a new ML feature engineering pipeline
