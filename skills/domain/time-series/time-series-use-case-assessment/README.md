# Time-Series Use Case Assessment

Assess a time-series use case and translate it into structured data and analytics requirements.

## What this skill does

This skill takes a time-series or sensor data use case and produces a structured assessment covering required signals, source systems, sampling frequency, history, latency, contextual data, data quality risks, and an ingestion approach recommendation.

It is designed for use cases involving sensor data, historian data, IoT telemetry, operational data, or any time-dependent analysis.

## When to use it

- A business or operations team wants to use sensor, process, or historian data for reporting, monitoring, or analytics
- You need to scope what signals and contextual data are required before designing an ingestion pipeline
- You are evaluating whether a use case requires real-time, near-real-time, or batch processing
- You are assessing a time-series use case for an AI or machine learning initiative

## Example use cases

- Assessing energy monitoring requirements across a manufacturing facility
- Scoping data requirements for equipment condition monitoring
- Evaluating the data needs for a production throughput analytics dashboard
- Defining requirements for a predictive maintenance proof of concept
