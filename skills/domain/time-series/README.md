# Time-Series Domain Skills

Skills for working with time-series, sensor, IoT, and industrial data.

## About this domain

Time-series data presents unique challenges compared to transactional or event-driven data. Signal frequency, irregular sampling, data gaps, outliers, and asset-contextual metadata all require specific handling that general-purpose data skills do not fully address.

The skills in this folder are designed for practitioners working with:

- Industrial sensor and historian data
- IoT telemetry
- Operational and process data
- Time-dependent analytics and forecasting use cases

## Skills in this folder

| Skill | Description |
|---|---|
| [Time-Series Use Case Assessment](time-series-use-case-assessment/) | Assess time-series use cases and translate them into data ingestion and analytics requirements |

## Relationship to core skills

Domain-specific skills in this folder extend and complement the core skills. After completing a time-series use case assessment, you may proceed to the core Medallion Architecture Designer or Data Pipeline Designer skills with time-series-specific context already defined.
