# Web Domain Skills

Skills for planning, deploying, and optimising public-facing websites.

## About this domain

Web projects combine infrastructure, content, SEO, and delivery automation in ways that general-purpose data skills do not fully address. The skills in this folder guide practitioners through the decisions that are specific to static websites: choosing and configuring hosting platforms, wiring up DNS, structuring content for search indexing, and getting a site verified and discoverable.

The skills are opinionated but platform-aware. Where a specific platform (Azure Static Web Apps, VentraIP, Google Search Console) is referenced, the guidance covers both the general pattern and the platform-specific detail.

## Skills in this folder

| Skill | Description |
|---|---|
| [Static Website Hosting](static-website-hosting/) | Plan and deploy a static website on Azure Static Web Apps with custom domains, DNS, IaC, and CI/CD |
| [Website SEO and Indexing](website-seo-and-indexing/) | Prepare a static website for search engine indexing and submit it to Google Search Console |

## Relationship to core skills

Web domain skills are self-contained. They do not typically feed into core data skills, but they may be relevant as a prerequisite when a data product needs a public-facing presence (e.g. a documentation site, a product landing page, or a skills library index).
