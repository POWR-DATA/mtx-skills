# Example Input

## Context

A static website is live at `https://www.powrdata.com.au`. It has two pages — a homepage and an AI Agent Skills page — both plain HTML files. The site is hosted on Azure Static Web Apps. DNS is managed at VentraIP. The site has no `sitemap.xml`, no `robots.txt`, and no canonical tags yet.

The owner wants the site indexed in Google and has access to the VentraIP DNS portal to add a TXT record for Google Search Console verification.

## Input provided

**Primary domain:** `https://www.powrdata.com.au`

**Pages:**
- Homepage: `https://www.powrdata.com.au/`
- AI Agent Skills: `https://www.powrdata.com.au/ai-agent-skills`

**Hosting platform:** Azure Static Web Apps (Free tier) — `staticwebapp.config.json` is in the repo

**DNS provider:** VentraIP (manual portal — can add TXT record)

**Google Search Console access:** Yes — can create a new property

**Existing SEO setup:** None — no canonical tags, no sitemap, no robots.txt

**HTML page titles:**
- Homepage: `POWR Data | Data engineering, architecture and analytics advisory`
- AI Agent Skills: `AI Agent Skills for Data Engineering | PowerData`

**HTML meta descriptions:**
- Homepage: `POWR Data provides principal-led data engineering, architecture and analytics advisory for practical, low-overhead delivery.`
- AI Agent Skills: `Reusable AI agent skills and lightweight delivery procedures for data engineering, analytics, data architecture, modelling and lakehouse workflows.`
